4.1 Experimental Settings

Benchmarks

  • CrossVid [3]：跨视频比较、时间理解和多视角推理；保留原生双视频单选题。
  • X-Stream [6]：多路流式理解；保留带音频的双路即时／回溯单选题，使用可见历史前缀。
  • CVBench [1]：跨视频对象关联、事件关联与复杂推理；保留双视频单选题。
  • MVU-Eval [2]：多视频感知、空间关系和推理；筛选双视频单选任务，进行纯视觉评测。
  • MVPBench [4]：多视频动作、质量及关系比较；按全部必需输入筛选原生双视频单选任务。
  • SYNCR [5]：合成场景下的跨视频空间、运动和对象推理；保留双路单选四选一任务。

Comparison Methods

  • Full Tokens（论文 [10] · 代码）：完整保留共享预处理输入。
  • Random（参考论文 [13] · 参考代码）：按模态稳定随机采样，作为无评分压缩对照。
  • FastV-AV（论文 [7] · 代码）：利用浅层注意力选择 token；本计划在第 5 层后剪枝。
  • FastVID-AV（论文 [9] · 代码）：根据时段密度与冗余选择、合并视觉 token。
  • DyCoke-TTM-AV（论文 [8] · 代码）：使用时间 token 合并模块 TTM，保留各组锚点。
  • OmniZip（论文 [11] · 代码）：利用音频引导视觉预算，并压缩时间冗余。
  • OmniSelect（论文 [12] · 代码）：结合 AudioCLIP、问题词性过滤与模态路由进行选择。
  • OmniPack（论文 [13] · 代码）：组合前端选择合并和模型内部剪枝。
  • FRO (Ours)（本地代码）：利用第 2 层特征、跨路支持及时间新颖性选择 token。

评测范围与筛选规则

项目纳入规则
原生双视频统计所有必需输入，包括参考视频、候选视频和裁剪片段；恰好两路，不从三／四路题中删视频凑成两路。
题型明确的单选题、至少两个选项、唯一有效标准答案；保留原始选项与语义。开放题、多选集合题和自由排序输出不进入主表。
任务子集使用发布评测 split 内全部符合条件的题；多个 split 分开记录，训练／开发数据不混入主表。
题量六集筛选后的 N 均待标注清单统计；CrossVid 的 4,531 双视频题不能直接作为双视频单选题数。
缺失数据分别记录符合条件、媒体可用、下载完成与评测完成的数量；缺失媒体不得被悄悄移出总分母。
输入身份按 video ID、裁剪起止及流编号标识输入；同源不同片段遵守官方题目定义。保留 bbox、对象指代等必要元数据，并同步坐标变换。
视觉集合音轨CrossVid / CVBench / MVU-Eval / MVPBench / SYNCR 主表禁用音频；可选音视频扩展单列，不混入纯视觉结果。
纳入清单冻结记录官方版本／commit、题目 ID、选项、答案索引、媒体映射与 SHA256；所有模型和方法共享同一题目集合。

评分与汇总

项目设置
确定性解析只解析唯一的 Answer: 标签或完整单选答案；允许官方编号／字母的一一映射；出现互相冲突选项时不猜测答案。
指标分母Accuracy = 正确题数 / 全部纳入题数；无法解析计错，同时报告解析失败、空输出、长度截断和运行失败。
子任务按官方类别报告准确率与题量；MVPBench 主表使用原始 Accuracy，原文归一化 proficiency 仅作单独补充指标。
比较与区间中途只比较共同完成题目；最终对相同题目进行配对比较，以共享视频连通组为簇 bootstrap 1,000 次，报告 95% CI。
跨集合汇总各集合独立报告；只有六集都完成且样本数非零时，计算六集 Accuracy 的等权平均。

方法配置与预算校准

Method固定设置
Full Tokens / RandomFull 保留共同输入全部 token；Random 按可用模态固定种子采样。
FastV-AV第 5 层后剪枝；前 5 层完整计算、保留的 KV 与注意力评分计入 FLOPs。
FastVID-AV全局整数视觉预算按时段分配；原有排序／合并；有音频时使用固定均匀音频基线。
DyCoke-TTM-AV仅 TTM，保留组锚点并使用整数预算；不启用动态解码 KV 压缩。
OmniZip有音频时启用音频引导；纯视觉输入使用明确的视觉路径，零音频 token，记录适配分支。
OmniSelect有音频保留 AudioCLIP 与词性过滤；纯视觉时固定视觉路由，保留视觉选择核心；辅助调用按实际执行计成本。
OmniPack前端选择 + 内部保留 50%；7B 第 18 层，3B 第 26 层；ηv/a=.25/.35，λ=.20，τv/a=.10/.05，ζ=.10。
FRO独立第 2 层评分；bridge=.30，top-k=3，coverage=.20，novelty=.20；同模态跨路支持；选中原始嵌入送入主解码器。
无音频统一处理不存在的模态预算为 0；不制造静音 token。新原生题目接口与无音频分支需在正式运行前完成适配验证。

FLOPs 与执行记录

项目统计方式
目标每题每模型先计算 FRO 45% / 35% 的成本目标，再对其他方法校准；不可达到的预算标为 infeasible，单独报告数量。
统计范围1 MAC=2 FLOPs；主解码器 + 额外评分前缀 + AudioCLIP + 选择／合并矩阵运算；统一标准化 64 解码步，并另记实际生成成本。
共同编码器压缩发生在编码后时，匹配预算不含共同编码器；端到端 FLOPs 与延迟另列并包含编码器。逐元素算子、排序等计数范围明确记录。
聚合FLOPs Ratio = Σ方法成本 / Σ同输入 Full Tokens 成本；按集合、模型、档位分别算。不得复用旧固定参考输入的百分比。
吞吐与恢复记录预处理、编码、评分、prefill、decode、峰值显存、题/小时；每卡独立输出，按题目 ID 去重，保留结果和输入指纹。
